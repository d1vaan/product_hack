# Как запустить стенд на MacBook — по шагам

Инструкция для того, кто не работал с терминалом. Делайте ровно по пунктам,
ничего не пропуская. Займёт 15–20 минут, из них большая часть — ожидание.

---

## Что вообще происходит

Стенд — это маленький сайт, который работает у вас на компьютере. Чтобы он
заработал, нужна одна бесплатная программа — **Docker Desktop**. Она сама
скачает и соберёт всё остальное. Вы вводите 2 команды, ждёте, открываете
браузер.

---

## Шаг 1. Установить Docker Desktop

1. Откройте в браузере: **https://www.docker.com/products/docker-desktop/**
2. Нажмите кнопку **Download for Mac**.
   - Если у вас Mac с процессором **Apple** (M1/M2/M3/M4) — выберите
     **Apple Silicon**.
   - Если Mac **старый, на Intel** — выберите **Intel Chip**.
   - Не знаете какой — нажмите меню  → «Об этом Mac». Там будет написано
     «Чип: Apple M…» или «Процессор: Intel».
3. Скачается файл `Docker.dmg`. Откройте его двойным щелчком.
4. В открывшемся окне перетащите иконку **Docker** в папку **Applications**
   (стрелка на картинке показывает куда).
5. Откройте **Launchpad** (F4 или иконка ракеты в доке), запустите **Docker**.
6. Появится окно с условиями — нажмите **Accept**. Дальше можно нажимать
   **Skip / Continue without signing in** — аккаунт не нужен.
7. Подождите. В строке меню сверху справа появится значок кита 🐳. Когда он
   перестанет дёргаться и станет спокойным — Docker готов.

> Docker Desktop должен быть **запущен** каждый раз, когда вы хотите включить
> стенд. Если закрыли — запустите снова из Launchpad.

---

## Шаг 2. Открыть терминал в папке стенда

1. Откройте **Finder**.
2. Перейдите в папку: **Рабочий стол → product hack → dev → demo-stand**.
3. Щёлкните по папке `demo-stand` **правой кнопкой мыши** (или Ctrl + щелчок).
4. В меню выберите **«Новый терминал в папке»**
   (по-английски «New Terminal at Folder»).

   Если такого пункта нет — включите его один раз:
   меню  → «Системные настройки» → «Клавиатура» → «Сочетания клавиш» →
   «Службы» → раздел «Файлы и папки» → поставьте галочку
   **«Новый терминал в папке»**. Потом повторите пункты 3–4.

Откроется чёрное (или белое) окно — это **терминал**. В нём вы будете
вводить команды.

---

## Шаг 3. Первый запуск

В окне терминала введите команду ниже. Проще всего — **скопировать её отсюда
целиком** и вставить в терминал (Cmd+V), потом нажать **Enter**:

```
cp .env.example .env
```

Ничего не произошло и появилась новая строчка — значит всё хорошо, идём дальше.

Теперь вторая команда — она соберёт и запустит стенд:

```
docker compose up -d --build
```

Нажмите **Enter**. Дальше **10–15 минут будет идти текст** — скачивание и
сборка. Это нормально. Не закрывайте окно.

**Готово, когда** текст остановился и в конце видно что-то вроде:

```
 ✔ Container fx-trigger-stand-proxy  Started
 ✔ Container fx-trigger-stand-web    Started
 ✔ Container fx-trigger-stand-api    Started
```

---

## Шаг 4. Открыть стенд

Откройте браузер и введите в адресной строке:

```
http://localhost
```

Должен открыться экран приложения с переводом. Готово.

Чтобы сразу посмотреть главный сценарий кейса («момент изменился») в режиме
разбора — откройте:

```
http://localhost/?scenario=S2&mode=review
```

Переключатель режимов **Демо / Разбор / Данные** — в тёмной полоске сверху.

---

## Как выключить

Вернитесь в терминал (то же окно в папке `demo-stand`) и введите:

```
docker compose down
```

Стенд остановится. Данные никуда не денутся.

## Как включить снова (в следующий раз)

1. Запустите **Docker Desktop** (Launchpad → Docker), дождитесь спокойного кита.
2. Откройте терминал в папке `demo-stand` (Шаг 2).
3. Введите:

```
docker compose up -d
```

(без `--build` — второй раз сборка не нужна, поднимется за несколько секунд).

## Как обновить, если файлы стенда поменяли

```
docker compose up -d --build
```

---

## Если что-то пошло не так

**«command not found: docker»**
Docker Desktop не установлен или не запущен. Вернитесь к Шагу 1, убедитесь,
что кит 🐳 в строке меню спокоен. Закройте и заново откройте терминал.

**«Cannot connect to the Docker daemon» / «Is the docker daemon running?»**
Docker Desktop не запущен. Откройте его из Launchpad, подождите минуту,
повторите команду.

**«port is already allocated» или «bind: address already in use» (порт 80)**
На компьютере уже что-то занимает порт 80. Самое простое решение — запустить
стенд на порту 8080:

1. Откройте файл `docker-compose.yml` в папке `demo-stand`
   (правой кнопкой → «Открыть в программе» → TextEdit).
2. Найдите строчку `      - "80:80"` и замените её на `      - "8080:80"`.
3. Сохраните файл (Cmd+S).
4. В терминале: `docker compose up -d`
5. Открывайте стенд по адресу **http://localhost:8080**

**Страница открывается, но всё пустое / крутится загрузка**
Подождите минуту после запуска — контейнеру `api` нужно время подняться.
Обновите страницу (Cmd+R). Если не помогло — в терминале введите
`docker compose logs api` и пришлите мне последние строки.

**Сборка `web` упала с красным текстом**
Введите в терминале `docker compose logs web`, скопируйте последние 20–30
строк и пришлите мне — поправлю.

**Хочу увидеть, что бэкенд жив**
Откройте в браузере `http://localhost/api/health` — должен показаться текст
с `"status":"ok"`. (Если меняли порт на 8080 — то `http://localhost:8080/api/health`.)

## Совсем кратко (шпаргалка)

```
# один раз
cp .env.example .env
docker compose up -d --build

# открыть
http://localhost

# выключить
docker compose down

# включить снова
docker compose up -d
```
