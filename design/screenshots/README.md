# Эталонные экраны текущего приложения

Сюда команда кладёт скриншоты веб-версии Альфа-Онлайн для сверки вёрстки:

- главная с сайдбаром и таб-баром «Главный · Платежи · Выгода · История · Чаты»;
- `Главный → Быстрые переводы → За рубеж → страна → форма → Продолжить`;
- экран перевода по номеру телефона (сегодня без курса и без строки
  «получатель получит» — плашка добавляет оба элемента);
- экран подтверждения (без строки комиссии).

Перед вёрсткой снять пипеткой цвета/радиусы/высоты и уточнить токены в
`web/tailwind.config.js`. Точность попадания в существующий стиль здесь важнее
скорости — кейс прямо оценивает опору на реальный клиентский путь.
